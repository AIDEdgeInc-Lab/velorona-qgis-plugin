# ۱۲ — راه‌اندازی پروفایل جداگانه QGIS برای تست پذیرش (فارسی)

وضعیت: روش زیر با QGIS 4.2.2 و همین فایل ZIP واقعاً آزمایش شد (در یک پروفایل موقت، با پنجرهٔ واقعی QGIS و همان تابع نصب-از-ZIP که منوی افزونه‌ها صدا می‌زند): افزونه بدون هیچ ایرادی نصب شد، ۸ عمل (Action) و Processing provider با نام velorona ساخته شد و نسخهٔ درون آن آزمایش (روی بستهٔ 1.1.9 کاندید قبلی) 1.1.9 بود؛ بستهٔ نهایی نسخهٔ 1.1.10 دارد. پروفایل معمولی شما در این آزمایش خوانده یا تغییر داده نشد. نسخهٔ رسمی تغییر نکرده است.

## چرا مشکل «نسخهٔ یکسان» پیش نمی‌آید
هر پروفایل QGIS پوشهٔ افزونهٔ خودش را دارد؛ پروفایل جدید افزونهٔ Velorona ندارد، پس 1.1.9 منتشرشده و کاندید با هم برخورد نمی‌کنند. (روی همین کامپیوتر چند پروفایل قدیمی با نسخه‌های مختلف Velorona وجود دارد؛ این هم جداسازی را نشان می‌دهد.)

**یک نکتهٔ مهم:** پایتونِ QGIS روی این کامپیوتر کتابخانه‌های قدیمی دارد (`aei-link-clearance` 0.1.0، `aei-microwave-link-exposure` 0.1.4)؛ کتابخانه‌ها بین پروفایل‌ها مشترک‌اند و افزونه نسخهٔ 0.2.x می‌خواهد (با 0.1.x تحلیل زمینی رد می‌شود). برای همین QGIS تست باید با کتابخانه‌های درست راه‌اندازی شود (ساخته شده‌اند در `~/velorona-acceptance/libs`)، بدون اینکه چیزی در پایتون یا پروفایل معمولی شما نصب یا عوض شود.

## مراحل
۱. QGIS معمولی را ببندید (اگر باز است).
۲. روی این فایل دوبار کلیک کنید (اگر macOS اجازه نداد: کلیک راست ▸ Open):
   `~/velorona-acceptance/start_acceptance_qgis.command`
   یا در Terminal:
   ```
   open -n -a /Applications/QGIS-final-4_2_2.app --env PYTHONPATH="$HOME/velorona-acceptance/libs" --args --profiles-path "$HOME/velorona-acceptance/qgis-profiles" --profile velorona_acceptance
   ```
   یک QGIS تازه (بدون افزونه‌های قبلی شما) باز می‌شود. پروفایل در `~/velorona-acceptance/qgis-profiles` ساخته می‌شود، نه در پوشهٔ QGIS معمولی شما.
۳. در همین QGIS: **Plugins ▸ Manage and Install Plugins… ▸ Install from ZIP** و این فایل را انتخاب کنید:
   `~/velorona-acceptance/release-1.1.10/velorona-1.1.10.zip`
   (SHA-256 باید با فایل `SHA256SUMS` کنار همان ZIP یکی باشد: `shasum -a 256 <مسیر فایل>`). سپس Install Plugin و در تب Installed تیک Velorona را بزنید.
۴. بررسی کنید: منوی Plugins ▸ Velorona **۸ عمل** دارد و در Processing Toolbox بخش **Velorona** هست. اگر آنها را دیدید، دستور کار `11_DESKTOP_ACCEPTANCE_PACK.md` را از مرحلهٔ ۱ ادامه دهید.
۵. برای مقایسه با 1.1.9 منتشرشده، همان QGIS معمولی خودتان را (با پروفایل معمولی) جداگانه باز کنید؛ هر دو را همزمان باز نگذارید مگر لازم باشد.

## برگشت به حالت عادی
- QGIS تست را ببندید (Cmd+Q). 
- QGIS را مثل همیشه (از Dock/Applications، بدون دستور بالا) باز کنید: پروفایل `default` شما با افزونهٔ 1.1.9 منتشرشده باز می‌شود. فایل `profiles.ini` معمولی شما در این روش دست نمی‌خورد (آخرین پروفایل همان `default` می‌ماند).
- پایان تست: برای پاک‌کردن کامل کاندید کافی است پوشهٔ `~/velorona-acceptance/qgis-profiles` را پاک کنید؛ به نسخهٔ منتشرشده ربطی ندارد.

## اگر مشکلی بود
- پیام «افزونه ... نسخه تکراری»: یعنی QGIS معمولی را باز کرده‌اید؛ دستور بالا را اجرا کنید و مطمئن شوید پنجرهٔ QGIS تست باز شده (پوشهٔ پروفایل: Settings ▸ User Profiles ▸ Open Active Profile Folder باید داخل `velorona-acceptance/qgis-profiles` باشد).
- پیام کتابخانهٔ قدیمی (library out of date): QGIS را با دستور بالا (با `--env PYTHONPATH`) راه‌اندازی نکرده‌اید.
- با اجرای این روش هیچ‌چیز commit، push، tag یا منتشر نشده است.

## داده‌های آمریکا (بدون تنظیم)
نیازی به USA Data Setup نیست: پس از Explore ▸ Load Public Data، روی نقشه به آمریکا بروید. با زوم کم، دایره‌های کم‌رنگ شمارش (USA overview) دیده می‌شوند؛ با زوم روی یک ایالت، لینک‌ها و کلاسترهای آمریکا خودکار و بدون هیچ دکمه‌ای بارگذاری می‌شوند. داده از سرور آنلاین Velorona (همان داده Velorona Map) فقط برای ناحیه‌ای که می‌بینید خوانده می‌شود. برای خاموش‌کردن: Explore ▸ USA Data Setup ▸ Turn USA data off.
