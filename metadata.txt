about=Velorona for QGIS -- Telecom link evidence, inside QGIS. 1. Explore -- Load public telecom infrastructure and your own data. 2. Select -- Choose a site, link, or two endpoints. 3. Analyze -- Run path clearance, microwave weather exposure, or satellite geometry. 4. Evidence -- See what is observed, what is calculated, and what is inferred. 5. Export -- Take the evidence with you as a structured CSV result or an Excel (.xlsx) workbook. Terrain clearance can also be run for many links at once (Processing Toolbox). United States FCC infrastructure loads automatically for the area you view (overview counts when zoomed out, detailed records and clusters when zoomed in; internet required). Three analysis engines, all reused unmodified: Terrestrial Path Clearance (aei_link_clearance), Microwave Weather Exposure (aei_mw_exposure), Satellite/Earth-Space look angles (skyfield/SGP4). Requires aei-microwave-link-exposure (0.2.0 or newer), aei-link-clearance (0.2.0 or newer), aei-geo-features, and skyfield to be installed in QGIS's own Python environment.
changelog=1.1.10 - Batch terrain clearance, USA data like Velorona Map, selection fixes, safer CSV exports
    NEW
    - Terrain clearance for many links. Processing Toolbox > Velorona > "Terrain clearance for many Fixed Service links", or Plugins > Velorona > Analyze: Terrain Clearance for Many Links (batch). Runs the same analysis as a single link for every link of a layer or for the selected links, one row per link with its status (CLEAR, WATCH, AT RISK, CRITICAL, NO DATA) and the reason, and the same Observed/Assumed typing of frequency and antenna heights. A link that cannot be analysed is NO DATA with its reason and never stops the others. Runs in the background with progress and Cancel (links not reached are listed as NOT RUN). Up to 100 links per run by default (1,000 maximum), optional pause between links, optional fallback frequency for records without one (typed Assumed), optional CSV. Terrain clearance only (no weather or satellite batch). The elevation service limits how fast links can be analysed: if it answers "too many requests" those links are reported as NO DATA to retry; use a pause of several seconds for more than a handful of links.
    - USA data now works like Velorona Map, with no setup. After Explore > Load Public Data, zoom to the United States: zoomed out you see pale count bubbles (an overview, not individual records, not selectable); zoomed in to a state-sized area the USA links and sites load by themselves, with Canada-style clusters, and follow you as you pan. Only the area you view is downloaded from Velorona's online USA data (internet required; one message tells you). Choose another source or turn it off in Explore > USA Data Setup. Very large views keep the overview; zoom in for records (limit about 36 map tiles or 20,000 links per view). An explicit Load USA Links in View now also shows the USA links in Records.
    FIXED
    - A selected record could stay selected, or be shown in the details panel, against a different record after a layer reloaded. Selection is now kept only for the same, unchanged record and cleared otherwise.
    - Selection did not respond for Velorona layers already in the project after the plugin was reloaded, and could answer twice; it now answers once per layer, also for layers added later.
    - Removing a Velorona layer no longer breaks the Records picker.
    - A Records row no longer stays highlighted when the map selection moved to a record hidden by the search; switching dataset shows that layer's own selection; the Records dataset and the QGIS active layer follow each other without selecting anything.
    SAFER EXPORTS
    - Text in CSV exports (names, identifiers, licensees, source and reason text) that begins with = + - or @ is now marked as text so Excel and Numbers do not run it as a formula. Calculated numbers, including negative values, are unchanged. The mark is a leading apostrophe, visible in a CSV. The Excel (.xlsx) export keeps the original text, stored as plain text.
    CLEARER
    - Terrain Details and the Excel summary now say where antenna heights and the frequency came from (the record's own value is Observed; a default or something you changed is Assumed), as the Evidence view and exports already did.
    - The optional imagery group is named "USA Aerial Imagery & Topo (USGS)" (off by default; projects saved with the old name are renamed). The plugin description no longer mentions a GeoJSON export (CSV and Excel). The Operator filter is stated to cover the Canadian layers.
    NOT CHANGED
    - Terrain clearance and weather calculations, thresholds, statuses, the Canada data and the satellite engine are unchanged (no change to those parts of the code since 1.1.9).
    REQUIREMENTS AND LIMITS
    - QGIS 4.0-4.99; aei-link-clearance 0.2.x, aei-microwave-link-exposure 0.2.x, aei-geo-features and skyfield must be installed in QGIS's own Python (see README).
    - USA data and the other live sources need internet access.
    - Satellite live-data behaviour could not be re-tested for this release (the orbital data service was unreachable); it is unchanged from 1.1.9.
    Earlier versions: see CHANGELOG.md in the repository (https://github.com/AIDEdgeInc-Lab/velorona-qgis-plugin/blob/main/CHANGELOG.md).
