about=Velorona for QGIS -- Telecom link evidence, inside QGIS. 1. Explore -- Load public telecom infrastructure and your own data. 2. Select -- Choose a site, link, or two endpoints. 3. Analyze -- Run path clearance, microwave weather exposure, or satellite geometry. 4. Evidence -- See what is observed, what is calculated, and what is inferred. 5. Export -- Take the evidence with you as a structured CSV result or an Excel (.xlsx) workbook. Terrain clearance can also be run for many links at once (Processing Toolbox). United States FCC infrastructure loads automatically for the area you view (overview counts when zoomed out, detailed records and clusters when zoomed in; internet required). Three analysis engines, all reused unmodified: Terrestrial Path Clearance (aei_link_clearance), Microwave Weather Exposure (aei_mw_exposure), Satellite/Earth-Space look angles (skyfield/SGP4). Requires aei-microwave-link-exposure (0.2.0 or newer), aei-link-clearance (0.2.0 or newer), aei-geo-features, and skyfield to be installed in QGIS's own Python environment.
changelog=1.1.12 - Accepts the 2026-11 security releases of the AEI libraries (aei-link-clearance 0.4, aei-microwave-link-exposure 0.3); no other change. 1.1.11 - Elevation from a raster of your own, local history, radar only inside Canada, data credits
    NEW
    - Elevation source: online (as before) or any single-band raster layer of your project. Elevation is typed Reference data (DEM), never Observed. A raster that does not cover the whole path, has nodata cells on it or has no coordinate system gives NO DATA with the reason; 0 m is never used.
    - Local history (this computer only, nothing is uploaded): weather values are kept for 24 h (1 h to 7 d) and a "What changed" block compares with them. History window with CSV export; your own site names are in the CSV only if you tick "Include my site names". Needs the optional aei-history-contract package.
    - Analyses, and the weather of a selected Fixed Service link, run in a background task; QGIS stays responsive.
    - Guide links: a "?" button and a Guide button on messages open the matching entry of map.velorona.ai/guide (message IDs shared with Velorona Map). Menu: Guide, and Get updates (opens map.velorona.ai/join in your browser; the plugin sends and counts nothing).
    - Data credits: Open-Meteo (CC BY 4.0) and the Copernicus DEM GLO-90 licence notice under results and in exports that used them.
    FIXED
    - ECCC radar is used only inside Canada, as in Velorona Map. ECCC's radar map answers 0 mm/h both where there is no rain and where no radar can see, so a US site showed an "Observed" 0.0 mm/h. Outside Canada the radar is now not asked, and the result says "Not covered"; nothing from it is shown or stored.
    CHANGED
    - "Predicted rain fade" is now "Estimated rain fade", derived from the current rain rate. Every model weather row states source, kind, time and unit.
    - Elevation values are cached and HTTP 429 is backed off by the library; the plugin's own terrain fallback is removed.
    REQUIREMENTS
    - QGIS 4.0-4.99; aei-link-clearance 0.3.x (was 0.2.x), aei-microwave-link-exposure 0.2.x, aei-geo-features and skyfield in QGIS's own Python; optional aei-history-contract 0.2.x for local history (see README). A library outside the range is reported when QGIS starts and the first terrain analysis is refused.
    NOT CHANGED
    - Thresholds, statuses, the Canada and USA data, and the satellite engine.
    Earlier versions: see CHANGELOG.md in the repository (https://github.com/AIDEdgeInc-Lab/velorona-qgis-plugin/blob/main/CHANGELOG.md).
